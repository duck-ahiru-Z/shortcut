【プレゼンテーション・マルチディスプレイ操作】（新規追加）
Windows + P
外部モニターやプロジェクターへの出力方法（PC画面のみ・複製・拡張・セカンドスクリーンのみ）を瞬時に切り替える

F5
（PowerPoint等で）スライドショーを「最初のスライドから」開始する

Shift + F5
（PowerPoint等で）スライドショーを「現在開いているスライドから」開始する

Esc
スライドショーや動画の全画面表示などを終了して元の画面に戻る

B / W
（スライドショー実行中に）画面を真っ暗（Black）、または真っ白（White）にして一時中断する（※注目を集めたい時に便利）

Ctrl + P
（スライドショー実行中に）ポインターを「ペン」に変更してスライドに書き込みをする

【文字入力・テキスト編集のステップアップ】
Shift + 矢印キー（↑↓←→）
文字を1文字（または1行）ずつ範囲選択する

Ctrl + 矢印キー（←→）
カーソルを「1単語ごと」にジャンプさせて素早く移動する

Home / End
カーソルを現在入力している行の「先頭」または「末尾」に一瞬で移動する

Ctrl + Home / Ctrl + End
ファイルやページの「一番上（先頭）」または「一番下（末尾）」に移動する

Shift + Home / Shift + End
カーソルの位置から、行の先頭（または末尾）までを一気に範囲選択する

Ctrl + B / Ctrl + I / Ctrl + U
選択した文字をそれぞれ「太字」「斜体」「下線」にする

Ctrl + Backspace
カーソルの左側にある文字を「1単語ごと」にまとめて削除する

Ctrl + Delete
カーソルの右側にある文字を「1単語ごと」にまとめて削除する

Ctrl + K
選択した文字にWebリンク（ハイパーリンク）を挿入する

【デスクトップ・ウィンドウの快適操作】
Windows + D
開いているすべてのウィンドウを最小化してデスクトップを表示する（もう一度押すと元に戻る）

Windows + 矢印キー（←→）
ウィンドウを画面の左右にぴったり合わせて配置する（画面分割に便利）

Windows + 矢印キー（↑↓）
ウィンドウを最大化、または元のサイズに戻す・最小化する

Alt + F4
現在開いているアプリやウィンドウを完全に終了する

Windows + V
過去にコピーした文字や画像の履歴（クリップボード）を表示し、選んで貼り付ける

Windows + I
Windowsの「設定」画面をすばやく開く

Windows + X
スタートボタンの右クリックメニュー（システムツールなどの一覧）を開く

Windows + 数字キー（1〜9）
タスクバーにピン留めされているアプリを、左からの順番に対応する数字キーで起動・切り替えする

【ウェブブラウザの素早い操作】
Ctrl + Tab / Ctrl + Shift + Tab
ブラウザのタブを右（または左）に順番に切り替える

Ctrl + 1 〜 9
左から数えて指定した番号のタブへ一瞬でジャンプする

Ctrl + L （または Alt + D）
アドレスバー（URL）を全選択状態にする（すぐに検索キーワードを入力できる）

Ctrl + D
現在見ているページを「お気に入り（ブックマーク）」に追加する

Ctrl + J
ブラウザの「ダウンロード履歴」画面を開く

Ctrl + ＋(プラス) / －(マイナス)
画面の表示を拡大、または縮小する

Ctrl + 0（ゼロ）
拡大・縮小した画面のサイズを100%（標準）にリセットする

Space / Shift + Space
ページを1画面分下へスクロール／上へスクロールする

Ctrl + Shift + Delete
ブラウザの「閲覧履歴データの削除」画面を一発で開く

【ファイル管理・システム操作】
Windows + E
エクスプローラー（ファイルやフォルダーを探す画面）を新しく開く

Alt + 矢印キー（↑）
エクスプローラーで、現在見ている場所の「1つ上の階層（親フォルダー）」へ移動する

Alt + 矢印キー（←→）
エクスプローラーやブラウザで、前の画面に「戻る」・先の画面に「進む」

Ctrl + Shift + N
新しいフォルダーをワンストロークで作成する

Shift + Delete
ごみ箱を経由せずに、ファイルやフォルダーを「完全に削除」する

Windows + L
パソコンの画面をロックする（離席時のセキュリティ対策）

Ctrl + Shift + Esc
タスクマネージャーを開く（アプリが固まったときの強制終了などに使用）

F11
ブラウザやエクスプローラーを全画面表示にする（もう一度押すと元に戻る）

Ctrl + マウスのホイール（上下）
デスクトップやフォルダー内のアイコンの大きさを自由に変更する
