# プロンプト：実務検定（シミュレーター形式） 1級・2級の問題生成

あなたはITエンジニア向けの「ショートカットキー学習Webアプリケーション」の問題作成者です。
このアプリには、実際にキーボードを打たせて判定する「実務検定（シミュレーター形式）」があります。
以下の仕様とJSONフォーマットに従い、**1級および2級の実務問題**をそれぞれ15問ずつ（計30問）作成してください。

## 【前提条件と難易度の目安】
対象となる級は以下の通りです。
*   **2級（上級・一般エンジニア/熟練事務レベル）**
    *   VS Code、Excel、ブラウザ等を息をするように操作できるレベル。
    *   対象: VS Codeのマルチカーソルや行移動、エクスプローラーの高度なファイル操作、高度な検索置換など。
*   **1級（神級・ハッカーレベル）**
    *   キーボードから一切手を離さず、開発や作業を爆速でこなすレベル。
    *   対象: VS Codeのコマンドパレット、ターミナル開閉、定義ジャンプ、PowerPointのショートカット、連続技など。

## 【制約事項（超重要：OSショートカットの禁止）】
本アプリはWebブラウザ上で動作するため、**OSレベルで横取りされてしまうショートカットキーは判定できません。**
以下のキーバインドは**絶対に出題しないでください。**
*   `Windowsキー` を含むすべての操作（Win+D, Win+L, Win+E, Win+V, Win+Shift+S, Win+Tab, Win+Ctrl+Dなど）
*   `Alt + Tab`（ウィンドウ切り替え）
*   `Ctrl + Alt + Delete`
*   `Ctrl + Shift + Esc`（タスクマネージャー）
※ アプリケーション（ブラウザ、Excel、Word、VS Code、PowerPointなど）内で完結するショートカットのみ出題してください。

## 【新機能：連続技（expectedKeySequence）について】
今回のアップデートで、**複数のショートカットを順番に入力させる「連続技（コンボ）」**の判定が可能になりました！
1級・2級の難易度に合わせ、実務でよく使う連続技を積極的に盛り込んでください。

**連続技の例：**
*   「現在のアドレス（URL）をコピーする」: `Ctrl + L`（アドレスバー選択） → `Ctrl + C`（コピー）
*   「Excelで一番上に戻ってから、全データを選択する」: `Ctrl + Home` → `Ctrl + Shift + End`
*   「エクスプローラーで名前を変更し、次のファイルの名前変更に移る」: `F2` → `Tab`
*   「VS Codeで同じ単語を3つ選択する」: `Ctrl + D` → `Ctrl + D`

連続技を使用する場合は、JSONで `expectedKeyCombo` の代わりに **`expectedKeySequence`** を使用し、配列の配列として定義します。
例: `"expectedKeySequence": [["control", "l"], ["control", "c"]]`

## 【問題作成のヒント：「あー！実務であるある！」と思わせるシチュエーション】
単に「〇〇を開け」ではなく、「マウスでやると絶望的に面倒くさいが、ショートカットを知っていれば一瞬で解決する」というカタルシスを感じられるシチュエーションを想定して問題文と解説を作ってください。

## 【キーの命名規則】
指定するキー名は以下の**小文字の文字列**のみを使用してください。
*   装飾キー: `"control"`, `"shift"`, `"alt"`
*   矢印キー: `"arrowup"`, `"arrowdown"`, `"arrowleft"`, `"arrowright"`
*   その他: `"enter"`, `"escape"`, `"space"`, `"delete"`, `"backspace"`, `"home"`, `"end"`, `"pageup"`, `"pagedown"`, `"tab"`, `"grave"`(バッククォート/Backquote), `"slash"`, `"period"`, `"comma"`
*   文字・数字: `"a"`, `"b"`, `"1"` など
*   Fキー: `"f2"`, `"f5"`, `"f12"` など

## 【出力JSONフォーマット】
以下の形式のJSON配列のみを出力してください。Markdownのコードブロック(```json ... ```)で囲んでください。
それぞれの問題には、詳しい解説（`explanation`）を必ず含めてください。IDは 2001~, 1001~ の連番としてください。

```json
[
  {
    "id": 2001,
    "type": "browser_copy_url",
    "question": "（ブラウザ）現在見ている参考記事のURLをチャットで共有したいです。マウスを使わず、アドレスバーを選択してからURLをコピーしてください。",
    "expectedKeySequence": [["control", "l"], ["control", "c"]],
    "answer": "CORRECT",
    "explanation": "Ctrl+Lでアドレスバー全体を選択し、すかさずCtrl+Cを押すことで、一瞬でURLをコピーできます。マウスでURLをドラッグする面倒さから解放される強力な連続技です。"
  },
  {
    "id": 1001,
    "type": "vscode_multi_cursor_down",
    "question": "（VS Code）JSONファイルのプロパティ10行に、一括でプレフィックスを付けたいです。現在行の下にマルチカーソルを追加してください。",
    "expectedKeyCombo": ["control", "alt", "arrowdown"],
    "answer": "CORRECT",
    "explanation": "Ctrl+Alt+↓は下にカーソルを複製するショートカットです。複数行の同じ位置を同時に編集できるため、置換機能を使うまでもない一括編集に絶大な威力を発揮します。"
  }
]
```
